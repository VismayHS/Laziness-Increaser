# React Frontend (Enhanced UI)

This frontend is a React + Tailwind layer for the existing backend endpoint:

- `POST /process`

## Run

Run from project root:

- `npm.cmd start`

This command installs frontend dependencies, builds the React frontend, and serves it from
Express on `http://localhost:3000`.
